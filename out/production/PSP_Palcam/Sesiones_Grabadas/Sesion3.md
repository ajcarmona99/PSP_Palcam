# Contenido
* Creacion de procesos e hijo.
* Comunicación.
* Sincronizan.
* Aplicación multiproceso.

# Caso práctico

Realiza una suma de varios proceso locales. Cada proceso
hijo recive los limites de una entrada que da el padre.

El hijo en caso de éxito escribe un unico entero.

# Ejercicio para casa

* Usa tres hijos.
* Envia un rango y cierra el escritor.
* Entre la llamada de un hijo a otro va a tener un limite 3 segundos.
* Mantener los modos ok, error, lento y formado.
* Si hay fallo mandalo a una carpeta.
* Documenta todo el código.
