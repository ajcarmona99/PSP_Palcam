# Contenido

1) Vamos a crear la clase con la que vamos a trabajar diferenciando 
entre cliente y servidor.
2) Conectar el servidor con el cliente sin enviar ningún tipo de mensaje.
3) Enviar el cliente al servidor <<Hola Ana>>
4) El servidor responde.
5) Que haya comunicacion por ambos lados, enviando mensajes entre el cliente y el servidor.
6) Vamos a ver como hacerlo en archivos distintos también.

# Ejercicio para casa

Tengo un servidor que espera dos numeros.

Primero el servidor manda al cliente dame un numero, el cliente manda el numero, el servidor comprueba si 
es un numero y luego le pide otro numero al cliente, el cliente manda su segundo numero, y el servidor calcula
la suma y se lo devuelve al cliente.
